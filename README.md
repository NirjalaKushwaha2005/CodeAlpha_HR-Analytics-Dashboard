# HR Analytics Dashboard

## Project Overview
This project analyzes employee attrition using Python and Power BI.
The objective is to understand employee turnover patterns and identify
factors associated with employees leaving the organization.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- DAX

## Key Performance Indicators
- Total Employees: 1,470
- Employees Left: 237
- Attrition Rate: 16.12%
- Average Monthly Income: 6,502.93

- ![HR Analytics Dashboard](visualizations/dashboard.png)

## Analysis Performed
- Attrition by Department
- Attrition by Age Group
- Attrition by Gender
- Employees Left by Job Satisfaction
- Employees Left by Education Field
- Employees Left by Overtime
- Average Monthly Income by Attrition

## Python Analysis
Python was used to inspect the dataset, calculate employee
attrition metrics, and generate visualizations using Pandas
and Matplotlib.

## Power BI Dashboard
Power BI was used to create an interactive dashboard containing
KPI cards, charts, and slicers for exploring employee attrition.

## Project Structure
- `data/` - HR dataset
- `python/` - Python analysis script
- `visualizations/` - Charts generated using Python
- `powerbi/` - Power BI dashboard file

## Key Findings
- 237 of 1,470 employees left the organization.
- The overall attrition rate was 16.12%.
- Sales had a higher attrition rate than the other departments.
- Employees who left had lower average monthly income than
  employees who stayed.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib`
3. Run the Python script:
   `python python/hr_analysis.py`
